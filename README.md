# 🛡️ KTCN Admin Portal - Trang Quản Trị Hệ Thống Khoa Tài Chính Ngân Hàng

[![React 18](https://img.shields.io/badge/React-18.x-61DAFB?style=for-the-badge&logo=react&logoColor=black)](https://react.dev/)
[![Vite 6](https://img.shields.io/badge/Vite-6.x-646CFF?style=for-the-badge&logo=vite&logoColor=white)](https://vitejs.dev/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.x-3178C6?style=for-the-badge&logo=typescript&logoColor=white)](https://www.typescriptlang.org/)
[![Tailwind CSS v4](https://img.shields.io/badge/TailwindCSS-v4-06B6D4?style=for-the-badge&logo=tailwindcss&logoColor=white)](https://tailwindcss.com/)

Bảng điều khiển quản trị (Content Management System - CMS) dành cho Ban quản lý **Khoa Tài Chính Ngân Hàng**. Hệ thống giúp đơn giản hóa công tác biên tập bài viết, quản lý banner quảng bá, cập nhật hồ sơ giảng viên và xử lý biểu mẫu thủ tục cho sinh viên.

---

## ✨ Tính Năng Nổi Bật

- 📊 **Dashboard Tổng Quan:** Thống kê lượt truy cập bài viết, bài viết mới xuất bản, số lượng biểu mẫu sinh viên đã tải.
- ✍️ **Trình Biên Tập Bài Viết Chuyên Nghiệp:** Biên soạn bài viết định dạng Rich Text HTML, chèn ảnh, ghim bài viết lên trang chủ.
- 🖼️ **Kéo Thả Banner (Drag & Drop):** Sắp xếp thứ tự hiển thị của các Slider Banner trực quan nhờ thư viện `@dnd-kit`.
- 👨‍🏫 **Hồ Sơ Cán Bộ & Bộ Môn:** Cập nhật thông tin giảng viên, học hàm học vị, phân phân bộ môn công tác.
- 🔑 **Phân Quyền Chi Tiết:** Quản lý tài khoản quản trị viên với các cấp độ truy cập an toàn.

---

## 🛠️ Công Nghệ Sử Dụng

- **Build Engine:** Vite 6 (Siêu nhanh, HMR tức thì)
- **Framework & Language:** React 18, TypeScript
- **Styling:** Tailwind CSS v4, Lucide React Icons
- **Form & Validation:** React Hook Form, Zod
- **Drag & Drop:** `@dnd-kit/core`, `@dnd-kit/sortable`
- **UI Components:** Radix UI, TanStack Table v8

---

## 🚀 Hướng Dẫn Cài Đặt

```bash
git clone https://github.com/nguyenhuynhdt37/ktcn-admin-portal.git
cd ktcn-admin-portal

# Cài đặt dependencies
npm install

# Khởi chạy Development Server
npm run dev
```

Mở trình duyệt: `http://localhost:5173`
