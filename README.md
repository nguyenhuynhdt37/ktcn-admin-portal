Bảng điều khiển quản trị (CMS) dành cho Ban quản lý **Trường Kỹ Thuật và Công Nghệ - Đại Học Vinh**. Cho phép biên tập bài viết, quản lý banner quảng bá, cập nhật hồ sơ giảng viên và xử lý biểu mẫu thủ tục sinh viên.

---

## ✨ Tính Năng Nổi Bật

- 📊 **Dashboard Tổng Quan:** Thống kê lượt truy cập bài viết, bài viết mới xuất bản.
- ✍️ **Trình Biên Tập Bài Viết:** Biên soạn bài viết định dạng Rich Text HTML, chèn ảnh.
- 🖼️ **Kéo Thả Banner:** Sắp xếp thứ tự Slider Banner kéo thả (`@dnd-kit`).
- 👨‍🏫 **Hồ Sơ Cán Bộ & Bộ Môn:** Cập nhật thông tin giảng viên, học hàm học vị, phân công bộ môn.

---

## 🚀 Hướng Dẫn Cài Đặt

```bash
git clone https://github.com/nguyenhuynhdt37/ktcn-admin-portal.git
cd ktcn-admin-portal
npm install
npm run dev
```
